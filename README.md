# ИИ: манга-конспект

Курс по искусственному интеллекту в формате манги. Девять страниц: от теста
Тьюринга до обучения с подкреплением.

**Сайт:** https://tleukhanov.github.io/ai_qairu_manga/

## Страницы

| # | Тема |
|---|---|
| 01 | Введение в ИИ |
| 02 | Агенты и среды |
| 03 | Поиск в пространстве состояний (BFS / DFS) |
| 04 | Эвристика и A* |
| 05 | Игры: минимакс и α-β отсечение |
| 06 | Логика и база знаний |
| 07 | Вероятности и Байес |
| 08 | Марковские процессы принятия решений (MDP) |
| 09 | Обучение с подкреплением |

## Как устроено

Чистая статика: HTML, CSS и немного JS. Без сборки и зависимостей.

```
index.html
assets/
  css/style.css
  js/reader.js     — прогресс чтения и навигация с клавиатуры
  img/*.webp       — 9 страниц
```

Навигация: стрелки ← →, пробел, PageUp / PageDown, Home / End.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://127.0.0.1:8000
```

## Деплой

GitHub Pages, ветка `main`, папка `/ (root)`.
